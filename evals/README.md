# Evals

Pasta de instrumentos de teste. Nenhuma resposta de modelo real, nenhum escore humano e nenhuma credencial está incluída neste repositório.

**Atenção:** artefatos `.jsonl` com prompts e respostas de avaliações podem revelar dados privados se você alterar os casos originais. Os resultados reais ficam fora do Git por padrão. Leia `docs/EXECUCAO-DO-EXPERIMENTO.md`.
