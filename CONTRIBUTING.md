# Contribuindo com o AXI

Prefira issues com: falha reproduzível, plataforma/modelo e versão, prompt sanitizado, saída obtida, saída esperada e grau de consequência. Nunca envie dados pessoais, tokens, documentos privados ou testes fabricados.

Contribuições científicas devem indicar *qual componente* foi estudado (A, X, I, conjunto), desenho do estudo, limitações e conflitos de interesse. Não declarar o método “comprovado” com base apenas em trabalhos sobre analogia, leitura ou multimídia.

Comandos locais: `python scripts/validate.py`; `python -m unittest discover -s tests -v`; `python scripts/build.py`. Antes de aceitar alterações, revise impactos em fontes, privacidade e formatos rígidos.
