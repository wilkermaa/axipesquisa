# axipesquisa v2.0.0 — oito distribuições, um método

A AXI é uma metodologia de explicação e pesquisa em português:

- **A — Análise:** "O que é/são o todo e suas partes?"; decomposição funcional e verificação.
- **X — eXpansão:** comparações com o mundo real, virtual, conceitual e, quando pertinente, filosófico/metafísico, com limites explícitos.
- **I — Integração:** funcionamento conjunto e relações dinâmicas, processos, decisões, prática e feedback.

**Saída:** explicações iniciam com `Orientação AXI aplicada`; referências externas **todas as efetivamente consultadas** são listadas no fim em ABNT; última linha `◌ AXI · nome ou e-mail autorizado`. Não contaminar artefatos de formato estrito.

**Distribuições:** ChatGPT Web, Gemini Web, Grok Web, Claude Web, Codex, Antigravity, Grok Build CLI, Claude Code.

**Ciência:** Descartes (análise), Meyer (contextos culturais), Dilts (heurística editorial da PNL, não validada como neurociência), Sweller (carga cognitiva) e Mayer (aprendizagem multimídia). **AXI não foi validado experimentalmente como método completo.**
