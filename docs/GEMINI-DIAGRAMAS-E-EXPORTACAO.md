# Gemini Web — diagramas visuais sem prévia Mermaid | AXI-Pesquisa v2.2.2

Se o Gemini fornecer apenas código `mermaid`, use a alternativa **SVG vetorial**. Se a sessão disponibilizar Canvas, gere uma página HTML autossuficiente com SVG inline e exportação SVG/PNG no navegador. Se não houver Canvas aberto, o usuário pode clicar **Adicionar arquivos (+) → Canvas**. Alternativamente, tarefas que permitam gerar arquivos podem criar diretamente `.svg` e `.png` e oferecer links de download.

## Aceitação

| Entrega | Obrigação |
| --- | --- |
| Fonte Mermaid | Sintaxe válida e compatível com relações reais |
| Gráfico visível | Prévia Mermaid, SVG exibido ou página Canvas com SVG visível |
| Arquivo SVG | Arquivo existente, com link verificável, ou código completo claramente rotulado como código |
| Arquivo PNG | Arquivo real ou controle funcional de exportação com suporte; sem link inventado |

A Skill **não pode forçar uma interface a abrir ferramentas indisponíveis**. A alternativa gráfica é mandatória como tentativa quando o usuário pede diagrama; seu sucesso só pode ser afirmado quando verificável.
