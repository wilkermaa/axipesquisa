# Licenciamento: decisão pendente

**Não há licença concedida nesta versão automaticamente.** O pedido de preparar um repositório GitHub não significa autorização para sublicenciar ou renunciar a direitos autorais.

Sugestões a avaliar com o titular do projeto:

- `MIT` ou `Apache-2.0` para os scripts auxiliares e automação de empacotamento.
- `CC BY 4.0` para documentação e instruções textuais, caso o titular deseje permitir reprodução com atribuição; ou licença única compatível com o modelo de distribuição que escolher.
- Atribuir explicitamente autores externos das ideias, sem copiar trechos longos de livros, imagens, diagramas proprietários ou terminologia de marca usada como falsa afiliação.

Após a escolha, registrar a licença oficialmente em arquivo `LICENSE` e revisar README e metadados. GitHub sem arquivo de licença, em regra, não equivale a autorização irrestrita de uso e redistribuição.
