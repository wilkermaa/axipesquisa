# AXI-Pesquisa v2.3.1 — Diagramação do Fluxo de Aplicação

**Categoria:** PATCH. **Data:** 11 nov. 2026.

A Integração deve verificar se o objeto estudado tem um fluxo de funcionamento ou aplicação e incluir um diagrama quando puder representá-lo fielmente. A regra vale mesmo sem pedido explícito. O fluxo mostra os caminhos sustentados e sinaliza lacunas relevantes. Relações estáticas são apresentadas sem atribuir uma ordem temporal.

**Caso de regressão:** explicar uma mudança de lotação sem pedir diagrama. O resultado esperado mostra a iniciativa, a vaga ou permuta, a decisão e o ato de formalização. Um caso estático verifica a ausência de uma sequência inventada.
